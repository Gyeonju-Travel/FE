## 1차 배포 — 제출 완료 (2026-08-22)

- TestFlight 배포용 iOS Bundle ID 변경 및 EAS 빌드/제출 설정
- 경주 마스터 스탬프 토스트 중복 지급 방지
- 회원가입 화면 키보드가 전화번호 입력란을 가리던 문제 수정
- 지도 "내 저장" 탭 검색이 주소까지 걸리던 것을 이름만 검색되게 수정
- 경주마스터 스탬프가 재빌드/재설치 때마다 축하 알림이 다시 뜨던 문제 수정
- 일정 취소 시 예약된 21시 알림도 같이 취소되도록 수정

## 2차 배포 — 미제출 (다음 빌드에 포함 예정)

- 홈 화면 관광지에 BEST 뱃지 표시 (첨성대·교촌마을·황리단길)
- 설정 화면의 이용약관/개인정보처리방침/위치기반서비스이용약관이 각자 다른
  문서로 연결되도록 수정 (전에는 셋 다 같은 화면으로 연결됨)
- 저장 페이지에서 삭제한 장소가 지도 화면(하트, 내 저장 목록)에 반영 안 되던
  문제 수정
- 장소 상세 바텀시트에 브레이크타임/휴무일 표시, 정보 없는 항목 아이콘 숨김
- 황리단길 스탬프가 토스트만 뜨고 스탬프 앨범엔 안 보이던 문제 수정
- 홈 화면 관광지 목록을 지정된 6곳(교촌마을/황리단길/계림/월정교/경주읍성/
  첨성대)으로 제한
- 알림 페이지 인사말 텍스트가 좁은 화면에서 여러 줄로 밀리는 문제 수정
- 지도 검색 결과 클릭 시 지도 이동이 안 되던 문제 수정
- 지도에서 좋아요(하트) 누르면 지도가 다른 위치로 리셋되던 문제 수정
- 장소 상세 바텀시트를 연 채로 다른 화면에서 저장/삭제해도 하트 상태가
  안 바뀌던 문제 수정
- 로그아웃/회원탈퇴 시 스탬프·진행 중이던 일정·최근 검색어 등 로컬 데이터가
  안 지워져서 재가입/다른 계정 로그인 때 이전 계정 상태가 섞여 보이던 문제 수정
- 완벽한여행 스탬프가 일정 완주 직후 스탬프 앨범에 안 보이던 문제 수정
- 경주 이탈로 일정이 자동 취소될 때 화면 이동 없이도 "여행중" 표시가 바로
  "시작"으로 돌아오도록 수정
- 관광지 스탬프 지급 시 서버 방문 기록을 축하 알림보다 먼저 남기도록 순서 조정
  (알림 누르자마자 스탬프 앨범 들어가도 반영 늦어 보이던 문제 완화)
- 마이페이지 프로필 카드 아래 섹션 간격 조정
- 회원가입 완료 환영 토스트가 "다음"으로 넘어가기 전까지 고정 표시되도록 변경
- 알림 페이지 인사말 텍스트가 좁은 화면에서 밀리던 문제 재수정
- 강아지 프로필 사진 없을 때 기본 일러스트가 중앙 정렬 안 되던 문제 수정
- 강아지 나이를 0~50 범위 밖으로 입력하면 인라인으로 바로 안내하도록 수정
- 강아지 추가 후 상단 프로필이 자동으로 그 강아지로 바뀌던 동작 제거
  (대표는 사용자가 직접 바꿀 때만 바뀜)
- 목록 화살표(›)를 텍스트 대신 벡터 아이콘으로 통일
- 설정/마이페이지 화면 피그마 스펙 정합화 (토글, 아이콘, 여백, 폰트 등 일괄 정리)
- 마이페이지 탭에서 하단 배경 일러스트가 탭 바 둥근 모서리까지 자연스럽게 이어지도록 조정
- 온보딩 2단계(반려견 크기 선택) 아이콘 2배 확대, 선택 시 배경/글씨 굵기 변경,
  라벨 위치 정렬, 화면 중앙 쪽으로 배치 조정
- 홈 화면 벨 아이콘을 누르면 뜨는 화면을 "업데이트 소식" 화면(UpdateNewsView)으로
  교체 (알림 없음 상태 없이 항상 안내 문구가 하단에 표시됨)
- 홈 화면 강아지 이름 옆 화살표 아이콘 간격 조정
- 홈 화면 섹션(상단 카드/추천 경로 카드/관광지 목록) 간 여백을 24px로 통일
- BEST 뱃지를 알약형(54x24) 디자인으로 변경
- 관광지/카페/식당 카테고리 뱃지·칩 색상을 코랄(#E8906A) 톤으로 전체 통일
  (저장 페이지 필터, 홈/지도/일정/추천경로/장소상세 카드 전부 반영)
- 홈 화면 관광지 카드, 업데이트 소식 카드 테두리를 그림자 효과로 변경
- 지도 검색창/카테고리 칩 영역 그림자가 아래쪽에서 잘려 보이던 문제 수정
- 지도 카테고리 칩 미선택 상태 색상(#F4F0E8 배경, #6B6260 글씨)으로 변경
- 지도/추천경로 결과의 좋아요(♥/♡) 표시를 텍스트 기호 대신 SVG 하트 아이콘으로 교체
- 지도 장소 상세 시트의 좋아요 버튼을 카드 세로 중앙에 정렬
- 지도 장소 상세 시트의 주소/전화/영업시간을 표 형식(구분선 있는 박스)으로 변경
- 저장 페이지 필터 칩 크기(68x36)/색상을 지도 페이지와 동일하게 통일
- 저장 페이지 편집 모드에서 카드 선택 시 배경/테두리 색상 조정
- 저장 페이지 편집 모드 삭제 버튼(상단 "삭제", 하단 "삭제하기") 활성 색상을
  경고색(#C84848)으로 변경, 상단 "삭제" 텍스트가 선택 여부와 무관하게 항상
  같은 색이던 문제도 같이 수정
