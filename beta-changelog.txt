견주여행 베타 수정사항 기록
(TestFlight 빌드/제출 요청 기준으로 묶음 — 새로 배포 요청하시면 "미제출" 구간을
그 배포의 "테스트할 내용"에 붙여넣고, 그 구간을 "제출 완료"로 넘겨드릴게요)

## 1차 배포 — 제출 완료 (2026-08-22)

- TestFlight 배포용 iOS Bundle ID 변경 및 EAS 빌드/제출 설정
- 경주 마스터 스탬프 토스트 중복 지급 방지
- 회원가입 화면 키보드가 전화번호 입력란을 가리던 문제 수정
- 지도 "내 저장" 탭 검색이 주소까지 걸리던 것을 이름만 검색되게 수정
- 경주마스터 스탬프가 재빌드/재설치 때마다 축하 알림이 다시 뜨던 문제 수정
- 일정 취소 시 예약된 21시 알림도 같이 취소되도록 수정

## 2차 배포 — 미제출 (다음 빌드에 포함 예정)

- 홈 화면 관광지에 BEST 뱃지 표시 (첨성대·교촌마을·황리단길)
- 설정 화면의 이용약관/개인정보처리방침/위치기반서비스이용약관이 각자 다른
  문서로 연결되도록 수정 (전에는 셋 다 같은 화면으로 연결됨)
- 저장 페이지에서 삭제한 장소가 지도 화면(하트, 내 저장 목록)에 반영 안 되던
  문제 수정
- 장소 상세 바텀시트에 브레이크타임/휴무일 표시, 정보 없는 항목 아이콘 숨김
- 황리단길 스탬프가 토스트만 뜨고 스탬프 앨범엔 안 보이던 문제 수정
- 홈 화면 관광지 목록을 지정된 6곳(교촌마을/황리단길/계림/월정교/경주읍성/
  첨성대)으로 제한
- 알림 페이지 인사말 텍스트가 좁은 화면에서 여러 줄로 밀리는 문제 수정
- 지도 검색 결과 클릭 시 지도 이동이 안 되던 문제 수정
- 지도에서 좋아요(하트) 누르면 지도가 다른 위치로 리셋되던 문제 수정
- 장소 상세 바텀시트를 연 채로 다른 화면에서 저장/삭제해도 하트 상태가
  안 바뀌던 문제 수정
- 로그아웃/회원탈퇴 시 스탬프·진행 중이던 일정·최근 검색어 등 로컬 데이터가
  안 지워져서 재가입/다른 계정 로그인 때 이전 계정 상태가 섞여 보이던 문제 수정
- 완벽한여행 스탬프가 일정 완주 직후 스탬프 앨범에 안 보이던 문제 수정
- 경주 이탈로 일정이 자동 취소될 때 화면 이동 없이도 "여행중" 표시가 바로
  "시작"으로 돌아오도록 수정
- 관광지 스탬프 지급 시 서버 방문 기록을 축하 알림보다 먼저 남기도록 순서 조정
  (알림 누르자마자 스탬프 앨범 들어가도 반영 늦어 보이던 문제 완화)
